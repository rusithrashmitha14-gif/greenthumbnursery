# Green Thumb Nursery & Master Landscaping (Tampa, FL)

A modern, high-performance website redesign for [Green Thumb Nursery](https://www.greenthumbnursery.com/) in Tampa, Florida (established 1953). Built with Next.js 14 (App Router), TypeScript, Tailwind CSS, Framer Motion, and Lucide React, featuring a luxury Botanical Light Theme.

## 🌿 Highlights

- **Botanical Light Aesthetic:** High-contrast forest typography (`#111E13` / `#1E2F20`), warm off-white surfaces (`#FAFCF8`), and emerald green accents (`#2D7A47`).
- **Signature Frosted Glass Card:** Apple-style translucent glassmorphism (`bg-white/70 backdrop-blur-2xl`) with live status beacon and dual CTAs.
- **Storytelling Parallax:** 4-phase master landscape engineering roadmap with sticky background parallax.
- **Interactive Before & After Slider:** Drag-to-compare scenario slider showcasing real completed Tampa Bay estate transformations.
- **5-Acre Nursery Inventory:** Searchable and filterable plant catalog (palms, specimen trees, flowering shrubs, Proven Winners® leafjoy®).
- **Multi-Step Quote Builder:** High-converting design consultation intake form with budget tiers, services multi-select, and real-time validation.
- **All Routes Fully Built:** `/services`, `/services/[slug]`, `/work`, `/work/[slug]`, `/plants`, `/gardening-tips`, `/about`, and `/contact`.

## 🛠️ Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React

## 🚀 Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

Build for production:

```bash
npm run build
npm run start
```
